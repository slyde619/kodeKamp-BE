# Project Overview

A simple collection of JavaScript scripts for string manipulation, data type exploration, and score grading.

---

### Files Included

- **`reverse.js`**: A script that manually reverses a string using a for loop (from the last index back to the first).

- **`grading.js`**: A script that checks a score (0–100) and prints a remark (Excellent to Very Poor). It also catches invalid numbers.
- **`notes.txt`**: Basic definitions and methods for **String** and **Number** data types.
