# JavaScript Practice Tasks

A collection of four small JavaScript challenges solved using loops and conditions — no built-in shortcuts like `.flat()`, `Set`, or `.filter()`.

---

## What's in here

| File                    | What it does                                                            |
| ----------------------- | ----------------------------------------------------------------------- |
| `flattenArray.js`       | Turns a nested array like `[[1,2],[3,4]]` into a flat one `[1,2,3,4]`   |
| `findCommonElements.js` | Takes three arrays and returns only the values that appear in all three |
| `findUniqueElements.js` | Removes duplicates from an array, keeping each value once               |
| `kabebToCamelCase.js`   | Converts `hello-there` → `helloThere`                                   |

---

## Why no shortcuts?

#### The goal is to understand _how_ things work under the hood — using loops, index tracking, and manual comparisons.
